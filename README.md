# 風水羅盤

離線可用的風水羅盤 App:量房屋坐向 → 填幾個資料 → 在平面圖上找出財位,並用白話說明原因。純 HTML / CSS / JavaScript,沒有伺服器、沒有外部資源,資料只存在使用者自己的裝置上。

## 功能

- **羅盤**:傳統金字漆盤(天池、後天八卦、洛書、二十四山與三元龍、二十四節氣、二十八宿、刻度),可拖曳甩動旋轉,天心紅線固定;可接手機指北針,3 秒鎖定讀數;讀數列即時顯示「向 175.0° 午山兼丙 · 坐 子」與兼向、壓線、磁北/真北差異提醒。
- **住宅**:宅向與大門朝向、建築類型、建成年份與整修(決定用哪一運排盤)、住戶(命卦)、磁北/真北與城市磁偏角。
- **平面圖**:範本(套房、2 房 1 廳、3 房 2 廳、店面、自訂矩形)或自己畫房間、門窗、大門;太極點與八方位扇形疊在圖上,五個圖層(財位、八宅、玄空、流年、無);可匯入平面圖照片描圖。
- **財位**:明財位(進門後斜對角遠端)、八宅生氣位、玄空旺星位、流年財星、住戶本命財位,整合成排序,附「為什麼」與現況檢查(靠牆、被窗或廁所影響等)。
- **報告**:八宅命卦、玄空九宮星盤與格局、流年盤與太歲三煞、各房間建議;可複製文字或存成圖片。

## 執行

Windows 直接執行 `start.bat`(會開啟 <http://127.0.0.1:5180/>),或:

```bash
cd fengshui
npm run serve      # python -m http.server 5180
npm test           # 引擎與介面邏輯的自動測試
```

瀏覽器的手機指北針需要「安全環境」(HTTPS 或 localhost);區網 `http://192.168.x.x` 讀不到感測器。要在手機上測感測器,請用 Capacitor 原生殼或 HTTPS 通道。

## 計算的依據與取捨

規則不憑記憶:八宅、玄空飛星、財位、坐向、流年、羅盤、感測器共 8 個主題各有研究報告,並由另一位獨立複查者用不同來源與程式重算;引擎再用約 2,000 筆查證過的向量做測試。流派有分歧的地方,`docs/DOMAIN_SPEC.md` 第 3 節列出預設與可切換的設定(設定面板的「進階流派選項」)。財位排序的權重是設計值,只有「星的順序」有傳統依據,所以畫面只顯示三段標籤、不顯示分數。

## 已知限制

- 手機感測器只用合成事件驗證過,**尚未在 iOS / Android 實機測試**(權限流程、校準、平滑手感、觸覺回饋都要實機確認)。
- 未內嵌楷體字型:Windows 有標楷體,Android 會用黑體或宋體顯示盤面文字。
- 平面圖外框固定為房間的外接矩形,畫不出 L 型外框;`southUp`(南上羅盤)設定在羅盤畫面尚未支援。
- 財位排序權重、太極點取法(面積重心)沒有古籍來源,屬設計決策,建議請風水老師審稿。
- 尚未包成原生 App;目前以網頁形式使用,可從瀏覽器加到主畫面。
- 與舊版八宅、玄空程式的差異清單見 `docs/DOMAIN_SPEC.md` 第 6 節。
