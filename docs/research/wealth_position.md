## 1. 結論摘要

1. **「財位」沒有單一定義，至少有四種互相獨立的層次**：(a) 明財位，即客廳（或該空間）進門的對角遠端角，屬空間幾何；(b) 暗財位，依房屋坐向或星盤推算，屬理氣；(c) 流年財位，隨立春換年；(d) 本命財位，依住戶命卦。台灣與香港大眾媒體最通行的是 (a)；專業玄空派則主張只有星盤旺位才算，並批評「進門對角」為坊間簡化（信心: 高）。
2. **明財位可寫成確定的幾何演算法**：取「進入該空間之門」的位置，找不在門所在牆上、距門最遠的 90 度凹角（矩形即遠牆兩角之一）。門偏左則財位在遠端右角，門偏右則在遠端左角，門居中則左右兩角並列（信心: 高，5 個以上來源一致；門居中兩角有 1 個少數來源只取青龍邊）。已用兩種獨立實作對 20 萬組隨機房間與門位置交叉，0 筆不一致。
3. **「45 度」與「對角」在窄長房間會不同**。來源多半只寫「進門 45 度斜對角」而不定義幾何；預設取遠端角，45 度射線命中點只列為可選顯示變體（信心: 中）。
4. **財位成立要有硬條件**：角落由兩面實牆構成（靠山），不是走道、不是門、不是廁所、爐灶或樓梯。財位若是窗、落地窗、陽台，在明財位派稱「財位見空」，視為缺陷，可用矮櫃、屏風、窗簾造「人工實角」；玄空派（吳尚易）則主張旺星位要開門窗納氣，兩派直接對立，需做成設定開關（信心: 中）。
5. **暗財位的三個主要來源**：八宅（依大門朝向定宅，取生氣位為主、延年次之）、玄空（向盤當運星 9 與生氣星 1，八白為退氣財星）、流年（八白正財，九紫、一白、六白為輔）。另有多個少數說法：以天醫為財位、「坐向雙位表」、紫白坐山入中表；其中「坐向雙位表」各來源互相矛盾，不建議採用（信心: 中）。
6. **八宅 8x8 游年表已確定**：用變爻法算出後，與游年歌八句、網易延年表、搜狐天醫表、東四命表逐格核對一致。舊引擎 `BAZHAI_MAP` 在 64 格中錯 18 格，全部是吉位：8 個宅的生氣與天醫互換（16 格），加上艮宅、坤宅的延年（2 格）（信心: 高）。
7. **流年飛星以立春換年**（不是元旦）。2026 丙午年中宮一白，八白在東、九紫在東南、六白在北、四綠在東北、五黃在南、二黑在西北。以三元甲子表和尾數和兩個獨立公式對 1900 到 2099 年逐年核對，0 筆不一致，並與 5 個網頁來源吻合（信心: 高）。
8. **九運 = 2024 到 2043（下元，立春換運）**，當旺 9、生氣 1、退氣 8。九運水火：北方為零神宜見水，南方為正神宜見山、忌水（李居明、FWD 轉述的玄學家）。玄空排盤的實際水位仍以該屋向盤為準（信心: 中）。
9. **財位是否放水（魚缸）是明確的流派分歧**：中文百科、潮紫微、英文站認為財位忌水；多篇魚缸文章認為明財位可養魚。預設不在財位主動建議放水，只在九運北方零神位提供「可選」提示（信心: 中）。
10. **店面與辦公室**：收銀台與老闆座位的共同硬條件是背靠實牆、面向入口、不與大門成一直線、不被樑壓；收銀台宜在龍邊（站在店內面向店門時的左手邊）；內財位（老闆室）優先於外財位（公共區）。收銀台不一定要在財位（信心: 中）。
11. **排序啟發式為本設計，非傳統數字**：`分數 = 100 x clamp(0..1, 0.30 幾何 + 0.25 玄空 + 0.15 宅卦 + 0.15 命卦 + 0.15 流年) x 環境乘數`，另有「玄空優先」預設檔。權重理由與可調整性見 2.7 節，僅「順序關係」有來源依據（信心: 低）。
12. **白話免責（可直接上架）**：「風水屬傳統民俗，這些建議是整理空間與佈置的參考，不保證財運，也不構成投資或理財建議。」

## 2. 規則與演算法（逐步，可直接寫成程式）

### 2.0 座標與名詞約定

- 平面座標：x 向右、y 向上；矩形房間 `[0,w] x [0,d]`；牆名 `bottom (y=0)`、`top (y=d)`、`left (x=0)`、`right (x=w)`；角名 `BL BR TL TR`；門位置 `pos` 為沿牆座標（bottom/top 用 x，left/right 用 y）。
- 平面圖「上」對應的羅盤方位角 `planUpBearing`，任一平面向量 (dx, dy) 的羅盤方位 = `planUpBearing + atan2(dx, dy)`（度，順時針）。
- 八宮各 45 度，坎（北）為 337.5 到 22.5，邊界歸順時針下一宮（設計決策；24 山兼向與空亡屬玄空模組）。

```js
const SECTORS = ['坎','艮','震','巽','離','坤','兌','乾'];   // 北,東北,東,東南,南,西南,西,西北
const sectorOfBearing = b => SECTORS[Math.floor((((b % 360) + 360) % 360 + 22.5) / 45) % 8];
```

- 向（facing）：八宅取「進屋後面對大門所在的方位」（搜狐）；坐 = 向 + 180 度；宅名取「坐」所在的宮（坐北朝南 = 坎宅）。玄空常以採光面或最大門窗為向，屬玄空模組的分歧，此處只引用其結果。
- 太極點（房屋中心）：用於把角落映射到八宮的參考點，定義（外框中心或面積重心）不歸本主題，見第 7 節。

### 2.1 A. 明財位

#### A2. 明財位幾何演算法

輸入：空間多邊形 `room`（逆時針頂點）、進入該空間的開口 `door`（所在邊、沿邊位置）、選項 `centerBand`（預設 0.10）。

```js
function mingCaiWei(room, door, opt = {}) {
  const band = opt.centerBand ?? 0.10;
  // 1) 候選 = 內角恰為 90 度的頂點，排除門所在邊的兩端點（矩形即遠牆兩角）
  const cands = room.vertices.filter((v,i) =>
      interiorAngleDeg(room, i) === 90 && !door.edgeEndpoints.includes(i));
  // 2) 距離 = 室內步行最短距離（矩形時等於歐氏距離）
  const d = geodesicFromDoor(room, door.point);
  cands.sort((a,b) => d[b] - d[a]);
  let out = [cands[0]];
  if (room.isRect) {
    const L = door.wallLength;
    if (Math.abs(door.pos - L/2) <= band * L) out = [cands[0], cands[1]];  // 門居中：兩角並列，遠者為 primary
  } else if (cands[1] && d[cands[1]] >= 0.94 * d[cands[0]]) {
    out = [cands[0], cands[1]];                                            // 多邊形：距離差 6% 內視為並列
  }
  return out.map(c => ({ corner: c, status: cornerStatus(room, c, opt) }));
}
```

規則對照（等價形式，已驗證與距離法一致）：進門者的視角下，門若在牆的左半，財位在遠端右角；在右半則在遠端左角。

- 門偏左、偏右、居中、居中容差內外、門在四面牆各一、正方形、寬扁房間，共十餘個矩形幾何案例已寫入 fixtures（`geom_*`），每個都用手推距離驗證。
- 「門居中」容差 `centerBand = 牆長 x 10%` 是本設計決策（來源只說「門開中間」，未給數值）（信心: 低）。
- 45 度射線命中點（可選顯示）：由門中心朝「遠離門較近端」的一側，以 45 度射入，取撞到的第一面牆之點；寬扁房間會落在遠牆中段而非牆角（fixtures `geom_variant_ray45_hit_point`，信心: 低）。

#### A4. 角落範圍檢核：財位成立、不成立、需調整

角落範圍 `zone` 預設 1.0 公尺（設計決策：櫃體常見 100 公分、封窗建議約 60 公分）；開口與角區重疊超過 5 公分才算。

| 狀態 | 條件 | 明財位派處理 | 玄空派處理 |
|---|---|---|---|
| `ok` | 兩面牆皆實、角區無開口 | 成立 | 成立 |
| `void_window` | 角區有窗 | 財位見空，扣分並給補救 | 視為納氣，不扣 |
| `void_floor_window` | 角區有落地窗 | 同上，補救為「人工實角」 | 同上 |
| `blocked_opening` | 角區有門或通道 | 不成立，改走暗財位 | 不成立 |
| `blocked_walkway` | 動線穿過角區 | 不成立 | 不成立 |

補救方法（來源皆為民俗性質）：

- 窗或陽台：屏風、窗簾、紗簾（設計家）；霧面貼紙或布簾，根本解為改實牆，財位「可透光不可透氣」（楊登嵙，Yahoo 2022-05-06）；封掉約 60 公分寬的窗或掛水晶珠簾（Ailan）。
- 落地窗佔財位：窗前放高度至少到窗台的矮櫃或書架，造「人工實角」，加不透光窗簾（易算數）。
- 走道：屏風或矮櫃隔開（開運發大財）。
- 樑壓：吊飾或綠植（Cosmart）；白色或黃色水晶柱（子奇，518）。
- 光線不足：加暖色燈或鹽燈（Cosmart、ETtoday）。
- 都不成立時：改看暗財位（潮紫微、易算數），或「較安靜、採光穩定、不妨礙通行的角落」（大漢家具）。

備註：一則搜尋摘要稱「落地窗並不構成財位見空」（Mobile01 討論串，403 未能開啟原文），與 Yahoo、Ailan、易算數、100 室內設計四處說法相反，判為單一未查證的少數說法，未採用。

### 2.2 B. 暗財位

**共同結論**：暗財位沒有單一來源定義。建議以三種來源同時建立，加上本命財位，並在介面標示各自的時間性：

| 來源 | 決定於 | 時間性 | 說明 |
|---|---|---|---|
| 八宅（宅卦） | 大門朝向（坐山） | 固定，至房屋使用年限 | 風水工作室稱「房屋大門財位」 |
| 玄空（向盤、山盤） | 建成年所屬的運、坐向 | 一個運 20 年 | 向星管財，山星管丁 |
| 流年 | 立春換年 | 一年 | 八白為主，九紫、一白、六白為輔 |
| 命卦（本命財位） | 住戶出生資料 | 終身 | 依八宅東西四命 |

#### B1. 八宅

步驟：

1. 由大門朝向（向）求坐 = 向 + 180，用 `sectorOfBearing` 得宅卦。
2. 用第 3 節表 T2 查生氣、延年、天醫、伏位（財運面）與五鬼、六煞、禍害、絕命。
3. 財運面排序：生氣 > 延年 > 天醫 > 伏位。網易稱延年「也是旺財星」但旺財效果不比生氣；八宅四吉星的財運描述（生氣財運大好，延年很好，天醫不錯，伏位小吉）見搜尋摘要（神機閣，403 未能開啟全文）。

分歧：有來源直接稱「八宅中天醫位就是暗財位」（搜狐 483022681），另有來源稱「延年星所在位置為財位」。本設計三者都保留為候選，以生氣為主、延年次之、天醫再次。

**大門財位**：依大門朝向定宅後取生氣位。例：大門朝南 = 坎宅，生氣在東南（風水工作室：大門開南財位在東南；與變爻表一致）。

#### B2. 玄空

- 原則：山管人丁，水（向）管財（108s、cafengshuinet）。財位優先看向盤。
- 財星判斷：當運星 9（旺）> 生氣星 1 > 八白（退氣財星）> 六白（偏財）。三六風水稱八白、一白、六白為三大財星；幸福空間（吳尚易）稱玄空盤中 9 與 1 是氣最強的星，其所在位置就是財位。
- 已核對樣本：九運丑山未向，向盤未方（西南）山向皆 9（雙星到向），東方向星八白為退氣財星（不宜見大水），北方坎宮向星一白（宜見小水旺財）。這與 cafengshuinet 對該盤的描述逐項吻合，且是用獨立實作重算出的盤（見第 5 節）。
- 玄空盤本身（含替卦、兼向）由玄空模組提供；本模組只吃「向盤、山盤各宮星數」。

#### B3. 流年

1. 以立春換年（元旦不換）。判斷日期先減去立春時刻。
2. 中宮星：`center = wrap(start - (y - startYear))`，start 為該元甲子起始年的中宮星（上元 1864 = 1，中元 1924 = 4，下元 1984 = 7）。尾數和的獨立公式：2000 到 2099 年為 `wrap(9 - digitSum(y mod 100))`，1900 到 1999 年為 `wrap(10 - digitSum(y mod 100))`。
3. 順飛：宮序 中、乾、兌、艮、離、坎、坤、震、巽，星數依序加 1（9 之後回 1）。
4. 財星價值見 T5。

#### B4. 命卦（本命財位）

- 本命財位 = 該命卦的生氣位為主，延年、天醫次之，終身不變（每日頭條、風水工作室）。
- 命卦計算與男女中宮寄宮（男寄坤、女寄艮）歸命卦模組，不在本主題。
- 多位住戶：預設取各人財位價值的平均；可選「主要收入者加倍權重」。

#### B5. 不建議採用的傳統表

- **坐向雙位表**（觀仁自在、中文百科、MyGoNews、風水工作室、LIVING FORM 皆有）：例如坎宅財位在正北與西南。各來源對震、兌、乾三宅互相矛盾（見 T8），出處不明，且與八宅吉位對不上（坎宅的西南是絕命位）。預設關閉（信心: 低）。

### 2.5 E. 催財擺設（五行、九運、民俗）

### 2.7 G. 財位候選排序啟發式（本設計）

#### 結構

候選 = (a) 各主空間的明財位角落（含狀態）；(b) 各宮位中「有兩面實牆的角落」。對每個候選位置 L，所在宮 S 由「房屋中心到角落」的方位決定：

```js
const PROFILES = {
  mingcai:  { G:.30, XK:.25, H:.15, P:.15, Y:.15, xkShan:.25, opening:'penalty' },   // 預設（台灣通俗）
  xuankong: { G:.10, XK:.40, H:.10, P:.15, Y:.15, xkShan:.25, opening:'reward'  } }; // 進階
const BAZ_VAL  = {生氣:1.0, 延年:.75, 天醫:.55, 伏位:.25, 禍害:-.3, 六煞:-.3, 五鬼:-.5, 絕命:-.6};
const XK9_VAL  = {9:1.0, 1:.8, 8:.7, 6:.3, 4:0, 7:-.2, 3:-.3, 2:-.2, 5:-.7};           // 九運專用
const YEAR_VAL = {8:1.0, 9:.8, 1:.6, 6:.6, 4:.2, 7:-.4, 3:-.4, 2:-.7, 5:-1.0};

comp(S) = { XK: (1-xkShan)*XK9_VAL[向盤[S]] + xkShan*XK9_VAL[山盤[S]],
            H : BAZ_VAL[宅卦視角下 S 的星],
            P : mean(BAZ_VAL[各住戶命卦視角下 S 的星]),
            Y : YEAR_VAL[當年流年星[S]] }
G(L)  = 1.0 明財位 primary；0.9 中門的第二角；0.5 有兩面實牆的其他角；0.2 單面實牆；0 其他
score(L) = 100 * clamp(0, 1, wG*G + wXK*XK + wH*H + wP*P + wY*Y) * env(L)
env(L): 排除旗標(toilet,stove,stairs,walkway,door_swing) -> 0；否則連乘
        opening（明財位派 0.5、玄空派 1.05）、toilet_adjacent 0.8、stove_facing 0.9、
        beam 0.9、dark 0.95、sharp 0.95、no_solid_wall 0.7，下限 0.4
```

排序同分時依 G，再依 P，再依 XK。輸出時永遠顯示明財位（標籤「明財位」），不論它的排名，並列出每一項的貢獻與扣分理由。

#### 各權重的理由與可調整性

| 項 | 預設權重 | 理由 | 調整 |
|---|---|---|---|
| G 幾何 | 0.30（玄空檔 0.10） | 台灣大眾最通行、可觀察、永久有效；但專業派批評它非精算，所以只佔不到三分之一 | 使用者切換檔位或滑桿 |
| XK 玄空 | 0.25（玄空檔 0.40） | 專業派的核心論述；向星管財；已可用獨立實作核對；但排盤有替卦、兼向的變數，故通俗檔不給最高 | 同上 |
| H 宅卦 | 0.15 | 八宅大門財位屬固定；來源說旺財效果生氣優於延年 | 可關閉 |
| P 命卦 | 0.15 | 本命財位終身有效，但只在單人或主要收入者時有意義 | 無住戶資料時整項歸 0，權重不重分配 |
| Y 流年 | 0.15 | 一年有效，屬「今年加分」；用 15% 避免年年推翻結構性排序 | 可關閉、可只顯示不計入 |
| 星值高低 | 見常數表 | 只有順序有依據：九運 9 > 1 > 8 > 6（108s、cafengshuinet、36fengshui）；流年 8 > 9、1、6（Cosmart、DesignHouse）；生氣 > 延年 > 天醫 > 伏位（網易、搜尋摘要）。數字大小為設計值 | 設定檔覆寫 |
| 環境乘數 | 見上 | 排除級與強烈建議級來自第 2.4 節；乘數大小為設計值 | 設定檔覆寫 |

## 5. 已用程式驗證的項目與結果

驗證程式放在暫存工作區（未寫入專案），使用 Python 3.13。結果如下。

   - 對舊引擎 `divine_bazhai.py` 的 `BAZHAI_MAP`：**64 格中 18 格錯誤，且全是吉位**：8 宅的生氣與天醫互換（16 格）、艮宅與坤宅的延年（2 格）。伏位 8/8、凶位 32/32 正確。

## 7. 未解決問題

1. **角區尺寸與各項設計常數**：`zone = 1.0m`、`centerBand = 10%`、多邊形並列門檻 6%、門沖重疊 50%、環境乘數，皆為設計值，來源沒有數字。需要使用者測試後校準。
2. **坐向雙位表的出處**：五個網站有兩到三種互相矛盾的版本，追不到原典；與八宅吉位對不上（坎宅西南為絕命）。若能找到原典，可能是某一個流派的合法規則。
3. **紫白坐山入中表為何每宅只取一顆財星**（三碧、六白、八白）：等價關係已驗證，選取原則未說明。
4. **玄空模組的接口**：向的定義（大門或採光面）、替卦、兼向、上山下水等，會改變向盤，進而改變玄空財位；本模組只吃向盤與山盤數字，需與玄空模組對齊。
5. **太極點（房屋中心）定義**：外框中心與面積重心會讓角落落入不同宮，尤其不規則平面；不歸本主題，但直接影響宮位判定。
6. **多人命卦衝突**：平均、主要收入者加權，或分別顯示，需要產品決策。
7. **九運交運的時點與「全面啟動」說**：主流為 2024 立春；一篇文章稱 2026 才全面啟動，未查證。
8. **玄關的處理**：僅有 MyGoNews 的落地窗案例與住展的批評可依；玄關半遮擋時取哪個門仍是本設計的折衷。
9. **樓梯作為財位排除條件**：只有一個來源明說，邏輯上合理但來源少。
10. **財位放水、放重物、放電器**：每項都有相反來源，本文以「預設不建議」處理，尚無進一步判準。
11. **流年凶星壓在明財位**（例如 2026 年五黃在南）：來源只給「凶星位要注意」的一般說法，沒有針對明財位落在凶星位時的處置；目前只做扣分與警語。
12. **職業別流年財位**（謝沅瑾）：僅單一來源，只驗證了與 2024 飛星一致，其他年份是否成立未知。
13. **英文與西式（BTB）財位**：遠端左角、東南方等與本文流派不同，未整合，只在英文來源列出。
