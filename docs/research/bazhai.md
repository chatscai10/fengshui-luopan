### 1.2 命卦 (A)

**步驟 1: 決定干支年 Y (立春為界)。**

```js
// birth: 出生時刻,已換算成 UTC+8 (見 1.2 註)。LICHUN[y]: y 年立春交節時刻 (UTC+8)。
function effectiveYear(birth, boundary = 'lichun_exact') {
  const y = birth.year;
  switch (boundary) {
    case 'lichun_exact':     return birth >= LICHUN[y] ? y : y - 1;                // 預設
    case 'lichun_date_only': return birth.date >= LICHUN[y].date ? y : y - 1;     // 不知出生時刻時的退路
    case 'lunar_new_year':   return birth.date >= lunarNewYear(y) ? y : y - 1;    // 農曆正月初一
    case 'gregorian_jan1':   return y;                                            // 不建議
  }
}
```

- 立春 = 太陽視黃經 315 度的瞬間 (維基百科「立春」、香港天文台)。1900 到 2100 年的台灣時間表已放在 `bazhai.json` 的 `meta.lichun_cst_1900_2100`。
- 出生時刻要先換成 UTC+8 再比。查 tz 資料庫 (Asia/Taipei): 1900 到 2050 年立春時刻的時鐘偏移量都是 +08:00,唯一例外是 1938 到 1945 年 (日本標準時 +09:00);台灣夏令時間從未涵蓋二月初。
- 出生時刻與立春相差在 2 分鐘內,程式應標「臨界,請確認出生時分」。時刻表誤差: 與 HKO 官方值比對 2019 到 2028 年零差異 (取到分),與 lunar_python 在 1900 到 2050 年最大差 46 秒。2051 到 2100 年只有 lunar_python 一個來源。
- 不知道出生時刻且出生日剛好是立春日: 標「跨界」,兩種結果都顯示 (每年只有 1 天,約 0.27% 的生日)。

### 1.6 八星實務用途 (D)

**先分「位置」與「朝向」兩個量:**

- **位置 (position):** 房間 / 大門 / 灶座 / 廁所 落在屋子的哪個方位 (從宅中心看出去)。
- **朝向 (facing):** 人面向 / 床頭指向 / 灶口指向 哪個方位。

兩者查的是同一張 8x8 表,差別只在「方位這個輸入值是什麼」。

完整用途矩陣見 2.7。核心規則:

1. **大門: 位置** 宜落生氣、延年、天醫 (伏位次之);忌落五鬼、絕命、六煞、禍害。(《八宅明鏡》: 四吉星宜開門、立向、安床、灶向)
2. **主臥: 位置** 宜落四吉方,夫妻房優先取女主人的吉方 (港台常見做法)。
3. **床頭朝向: 朝向** 依目的選: 生氣主事業財運、天醫主健康與康復、延年主感情與長壽、伏位主安定 (幼童、靜心)。這是現代港台與西方做法;古法只論床「所在方位」(見 3.6)。
4. **書桌 / 辦公桌: 朝向** 坐下時面向的方位: 首選生氣,次選延年 (人際、人資類工作) 或天醫;學齡幼童面向伏位,考生面向生氣 (Feng Shui Store)。
5. **爐灶: 灶座論位置、灶口論朝向。** 古法與台港主流: 灶座壓在凶方 (絕命、五鬼、六煞、禍害位),灶口朝向吉方 (「坐凶向吉」),燒火的人背對吉方、面對火門才是真吉向。
6. **廁所: 位置** 宜落凶方 (五鬼、絕命、六煞、禍害) 以壓煞;忌落生氣位 (幾乎所有來源一致),延年、天醫、伏位位亦忌。
7. **客廳 / 財位: 位置** 沙發、魚缸首選生氣位,次選伏位 (《八宅明鏡》網頁的現代加註,標明「不屬於原書」)。

### 1.7 八宅論財 (E)

- 生氣 (貪狼木): 財、丁、官祿、名聲,最主要的財位。古籍說合得生氣方「逾月可得大財」。
- 延年 (武曲金): 財運好、長壽、夫妻和睦。古籍說「日日得財」。
- 天醫 (巨門土): 健康、貴人、財。古籍說「富有千金、家無疾病」;香港有派稱「天醫 = 財位」。
- 伏位 (輔弼木): 小富中壽,安穩。
- 五鬼 (廉貞火): 傳統定義主退財、火災、失竊、口舌官司、疾病。**「五鬼運財」是少數派技法**,見 3.10。
- 絕命 (破軍金) 最凶,主絕嗣、惡疾、退財;六煞 (文曲水) 失財、桃花;禍害 (祿存土) 官非、散財。
- **程式財位建議: 個人財位 = 依序取命卦的 生氣、延年、天醫 三方位 (預設序),伏位只當備位。** 疊上「屋內實際房間 / 平面圖」時,以「該方位落在客廳、書房、辦公區為佳,落在廁所、廚灶座為破」判斷。

## 3. 流派分歧與建議預設

### 3.1 年的分界 (命卦用哪一天換年)

| 做法 | 誰在用 | 評價 |
|---|---|---|
| 立春交節時刻 (精確到分) | 干支曆 / 八字系統;香港白鶴鳴派 (白如雪博士 2019 文以 2020、2021 兩例說明);搜狐研易人士;周易人命網速查表 | 傳統風水與命理的標準做法,建議預設 |
| 立春日期 (只比日) | 各種速查表 (如 Feng Shui Store 的「As from Feb-04 / Feb-05」表) | 無出生時刻時的退路;遇到立春當天出生會誤判 |
| 固定 2/4 | Dr Michael Oon 等英文站 (「4 Feb 到 3 Feb」) | 2017、2021、2025 這類立春在 2/3 的年份會錯 |
| 農曆正月初一 (春節) | Your Chinese Astrology、Feng Shui Mall (寫 LUNAR year)、新加坡 Master Sean Chan | 民間「過年換歲」直覺;與立春法在約 2.0% 的日子結果不同 |
| 西曆 1/1 | 簡易計算器 | 不建議;與立春法在約 9.4% 的日子結果不同 |

- 通行度 (信心: 中): 風水 / 命理專業文章 (香港、大陸、台灣命理師) 以立春為主流;英文圈與新馬網站混用春節與固定 2/4。我找到的台灣來源 (潮紫微、靈匣網) 的公式頁沒有明講年界,不能宣稱「台灣一律用立春」。
- 分歧量化 (1950 到 2050 年逐日掃描,以中午 12:00 出生計): 立春法對春節法有 2.04% 的日子不同,立春法對元旦法有 9.44% 的日子不同。春節與立春的日期差在 -14 到 +16 天之間,平均 1.0 天。
- **建議預設: `lichun_exact`。可選開關: `lichun_date_only`、`lunar_new_year`、`gregorian_jan1`。** 輸入介面在出生日落入「春節到立春之間」的視窗時,顯示兩種結果與差異提示。
- 典型判例: 2000-02-04 20:40 才立春,而春節是 2000-02-05;所以 2000-02-04 傍晚出生者,立春法為 2000 年 (庚辰,離 / 乾),春節法為 1999 年 (己卯,坎 / 艮)。

### 3.2 5 入中的寄宮

### 3.3 遊年星的錨點 (「伏位」放在哪裡)

Uncle Kin 彙編列出至少五種「定遊星、起伏位」法: 年命起伏位、坐山起伏位、門上起伏位、向上 (原文「向四」) 起伏位、高房起伏位。同一張 8x8 表,只是「本卦」取誰:

| 起伏位法 | 本卦取 | 用途 |
|---|---|---|
| 命盤 (人) | 個人命卦 | 大門 / 床 / 灶口 / 書桌 對人的吉凶。《八宅明鏡》「依命不依宅」的核心 |
| 宅盤 (坐山) | 宅卦 | 判斷屋子各房間本身的吉凶;宅命是否相配 |
| 門上、向上、高房 | 門卦 / 向卦 / 高房卦 | 少用,主要用於「要不要開後門後窗」等細項。趙九峰《陽宅三要》本身即以門上起伏位為方位吉凶依據 (易安居吉祥網) |

**建議預設: 同時輸出「命盤」(主) 與「宅盤」(輔) 兩層。** 床、灶口、書桌用命盤;大門與整屋相配度並看宅盤。(信心: 中)

### 3.4 宅卦取「坐」還是「向」

傳統中文資料 (《八宅明鏡》、各站) 一致以「坐」命名 (坐北朝南 = 坎宅)。英文 Feng Shui Store 同樣以 sitting position 命名,但該站留言區有一則回覆說「依朝向所在扇區定 house gua」,前後不一致。建議預設: 坐。(信心: 高)

「向」如何取: 八宅傳統以大門所向為向;實務上高樓公寓的大門方向與建築採光面常不同 (Feng Shui Store 亦說「這不是判斷朝向的標準規則」)。App 應讓使用者選「以大門為準 / 以陽台採光面為準 / 輸入羅盤角度」,預設大門。

### 3.6 位置法與朝向法

- **古法 (《八宅明鏡》網頁所載卷下灶卦部分,信心: 中):** 「灶座論方不論向,灶口論向不論方」;「房門、床、碓、廁之類,只論背座之方,不論向」。
- **現代港台與西方:** 床頭朝向、書桌面向、爐灶朝向大量使用;Feng Shui Store 直接主張「朝向比位置重要」。
- **建議預設: UI 分「位置」與「朝向」兩區。** 位置區只回答「這個房間、大門、灶座、廁所落在哪個星位」;朝向區回答「床頭 / 書桌面向 / 灶口朝哪個星位」。兩區不互相扣分。

### 3.7 爐灶: 灶座放凶方還是吉方

- 灶座放吉方: Feng Shui Store 稱天醫位適合放爐灶;香港 Feng Shui Beginner 把生氣、延年、天醫列為宜廚房 (信心: 中,少數派)。
- **建議預設: 坐凶向吉。開關: 「廚房位置偏好吉方」。**

### 3.9 六煞是不是桃花吉方

多數派: 六煞是凶星,失財、口舌、桃花糾紛。香港 Feng Shui Beginner 指出六煞宜作廁所,並說「單身人士居室可用,主桃花人緣佳」;明天機引述香港某名師稱六煞為桃花吉方。**預設: 仍列為凶;在「感情 / 單身」建議中提示桃花說法為少數派。**(信心: 中)

### 3.10 五鬼運財 (少數派)

- 說法一 (八宅內): 五鬼廉貞屬火,若八字喜火,把廚房 (火) 放在五鬼位或灶座壓五鬼,可「以凶化吉」(新浪 李光東文)。古法灶座壓凶位表中亦有「灶坐五鬼: 橫發資財」一項 (Uncle Kin 彙編)。
- 說法二 (紫白 / 輔星水法): 借廉貞星做水法招偏財,需專業羅盤佈局 (台灣文民)。
- 說法三 (民間法術): 拜五鬼、施符咒搬運財富,屬道教民俗偏財術,與八宅無關,來源多為商業網站,不採信。
- 反面: 搜狐星座文把五鬼位有廚房、睡房、廁所稱為「五鬼偷金」,主難聚財 (該文混用了八宅五鬼與玄空五黃)。
- **預設: 五鬼 = 破財凶位,不做「運財」推薦。** 只在進階說明或「少數派技法」摺疊區提及,並註明依賴八字喜忌、無公開可驗證標準。(信心: 中,存在此說;低,有效性)

### 3.11 財位是哪個星位

- 多數: 生氣 > 延年 > 天醫都主財 (搜狐易經堂: 生氣財運大好、延年很好、天醫不錯、伏位小吉)。
- 香港一派: 「天醫 = 財位」(明天機轉述)。
- **預設序: 生氣 > 延年 > 天醫。開關: 天醫優先。**

### 3.12 其他

- 鬼門線: 搜狐研易人士加了一條 15 度寬、沿東北到西南軸的「鬼門線」,大凶,不可穿過門、床頭、坐便器、灶台。只有一個來源 (信心: 低),預設不啟用。
- 24 山邊界與兼向 (「差一度」): 本主題採 8 個 45 度扇區。分金、兼向、空亡線的處理由 24 山主題另行研究,這裡只保證「山的邊界恰好落在扇區邊界」。

## 6. 未解決問題

1. **台灣民間實務的年界比例。** 找不到台灣的統計或權威聲明;只能確定專業文獻偏立春,民間與英文圈混用春節。需要之後由使用者反饋或做小範圍調查。(信心: 未知)
2. **2051 到 2100 年立春時刻** 只有 lunar_python 單一來源 (DE421 星曆只到 2053 年),誤差可能達 1 分鐘。實際使用者在 2051 年後出生的機率為零,對 App 無影響,僅標註。
3. **扇區邊界的開閉** (例如剛好 22.5 度) 資料來源沒有規定;本報告採 [起, 止) 半開區間。羅盤實測靠近邊界的「兼向 / 空亡」提示屬 24 山主題。
4. **《八宅明鏡》原書版本。** 網路上有多個版本,本次只讀到第一風水網一份,並含現代加註;灶座灶口與床的細則位於該頁「卷下」,出處章節未能對照影本。「灶座論方不論向」等句的信心因此定為中。
5. **少數派技法沒有可驗證標準。** 五鬼運財、鬼門線 15 度、六煞桃花吉方的主張,均為單一或少數來源。
6. **1938 到 1945 年台灣出生者** 的紀錄時間是日本標準時 (+09:00)。引擎需要在輸入層做時區換算;是否值得在 UI 露出,屬產品決策。
7. **多門住宅、公寓的「向」怎麼取。** 傳統八宅以大門為向,但高樓常有多個門與陽台。App 預設大門,並提供覆寫。是否要加「半自動建議」需要與玄空主題的朝向判定一起設計。
8. **等級排序 (延年 vs 天醫) 與財位序** 有分歧 (3.8、3.11),已給預設與開關,但沒有權威裁決。
9. 本報告只記錄流派主張與可計算的規則,不代表對吉凶效果的任何保證;App 文案應使用「傳統上認為」等中性語氣。
