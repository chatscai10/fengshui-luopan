## 1. 結論摘要

1. **24 山**:360° 均分 24 山,每山 15°;子山中心 0°,範圍 352.5°~7.5°;順時針排列 `子癸丑艮寅甲卯乙辰巽巳丙午丁未坤申庚酉辛戌乾亥壬`。每 3 山構成 1 卦,即 45° 一卦:坎 337.5~22.5、艮 22.5~67.5、震 67.5~112.5、巽 112.5~157.5、離 157.5~202.5、坤 202.5~247.5、兌 247.5~292.5、乾 292.5~337.5。已用程式對 108s 的 24 行度數表逐行比對,零差異。(信心: 高)
2. **只用地盤正針**:玄空只用地盤正針;八宅以 45° 八方位判定,同樣讀地盤數字。三合派另用人盤中針(子中心 352.5°,相對地盤逆時針 7.5°)與天盤縫針(子中心 7.5°,順時針 7.5°)。App 預設只實作正針,三針放進進階選項。(信心: 玄空高、八宅中;三針偏移方向的細節: 中,請用實體三合羅盤覆核)
3. **坐與向**:向 = 坐 + 180°,即 24 山 index + 12。八宅的宅卦由「坐山」所屬的卦決定(坐北向南 = 坎宅)。「以向代坐」是常見錯誤。(信心: 高)
4. **「向」怎麼取,流派沒有共識**。台灣室內設計與房產專欄常見說法:有陽台/落地窗以最大採光面優先,沒有才用大門;傳統與八宅古法「以門立向」;整棟大樓同一個正面(「大小太極」,搜尋摘要稱 Joey Yap 主張此說,未取得原文);Lillian Too/WOFS 主張 9 樓以下用大樓入口朝向、9 樓以上用自家最大景觀窗或陽台。建議預設見 4.1。(信心: 中)
5. **兼向門檻**:一山 15° 分 5 格、每格 3°;中間 9°(距山中心 ±4.5°)為下卦(正向),外側各 3° 為兼向。這是沈氏玄空學系統與多數玄空來源的說法,香港陳癸龍稱後學多以 4.5° 為準。少數流派用 ±3.5° 或 ±3°。建議預設 4.5°,做成可選開關。(信心: 中高)
6. **兼向限度與空亡**:同陰(子癸、午丁、卯乙、酉辛)兼至 6°;同陽(乾亥、坤申、艮寅、巽巳)兼至 7°;陰陽互兼(地元與天元)與出卦(人元與地元跨卦)限度為 5°(36fengshui)或 6°(zggdfs)。程式以 (okMax, voidAbove) = (5, 6) 兩段式表示。卦與卦交界線 = 大空亡,卦內山與山交界線 = 小空亡(位置式定義)。另有一套「差錯 = 小空亡、出卦 = 大空亡」的度數式定義。(信心: 分類結構中、限度數值低)
7. **手機羅盤精度**:理想條件下 ±2~5°,室內鋼筋結構最壞可達 30~90°;而一格分金只有 3°。因此手機只能做「山」的判定與「是否落在兼向區」的提示,不能做分金級判定。App 必須多次量測並用**圓周平均**。(信心: 中)
8. **磁偏角(2026.0,WMM2025)**:台北 -5.03°、台中 -4.71°、高雄 -4.32°、花蓮 -4.79°、香港 -3.29°、北京 -7.53°、上海 -6.53°、東京 -7.91°、首爾 -8.99°、新加坡 +0.21°。負 = 磁北在真北西側。台灣網頁上常見的「-3~-4°」是舊資料:IGRF-14 台北 1990 -3.25°、2000 -3.44°、2010 -3.86°、2020 -4.67°、2025 -4.99°。(信心: 高)
9. **換算符號**:`真方位 = 磁方位 + D`(D 東偏為正),`磁方位 = 真方位 - D`。台北一帶面向真北時羅盤讀數約為 005°,不是 355°。至少有一篇台灣中文文章把符號寫反,已用 fixtures 鎖定正確方向。(信心: 高)
10. **是否校正磁偏角**:傳統羅盤讀磁針,多數風水師不校正;少數主張改用真北。因為台灣的偏角約 4.3~5.1°,已超過一格分金(3°),不校正與校正會讓約 34%(台北)的方位換到另一座山、約 11% 換到另一個卦。建議預設「不校正(磁北,同實體羅盤)」,設定裡放明顯的「真北校正」開關,兩種讀法結果不同時並列提示。(信心: 中)
11. **舊引擎有錯**:`divine_xuankong.py` 的 `SHAN_YINYANG` 24 山中有 8 山陰陽寫反(子、卯、午、酉 應為陰;寅、巳、申、亥 應為陽),三元龍註解也與來源不符,且完全沒有度數概念。新 App 不可沿用。(信心: 高)
12. **驗證**:規則以 Python 與兩份獨立的 Node 實作交叉驗證;24 山表、陰陽表、三元表、兼向 48 局清單皆與網頁來源逐項比對通過;磁偏角模型對 NOAA 官方測試向量最大差 0.005°。

## 2. 規則與演算法(逐步,可直接寫成程式)

### 2.1 座標約定與 24 山索引

- 方位角 `bearing`:度,自北順時針,正規化到 [0, 360)。
- 24 山 index:`0 = 子`,順時針,中心 `15 * i`。
- **半開區間** `[start, end)`,`start = center - 7.5`。邊界值(如 7.5°、352.5°)歸順時針側的下一座山。這是純程式約定;傳統上壓在界線上叫「騎線」,本身就是空亡,沒有公認歸屬。(信心: 中,約定)
- 偏差 `dev = bearing - center`,範圍 [-7.5, 7.5),正 = 順時針側。

```js
const norm = (b) => ((b % 360) + 360) % 360;
const mountainIndex = (b) => Math.floor(((norm(b) + 7.5) % 360) / 15) % 24;
const deviation = (b, i) => (((norm(b) - 15 * i + 180) % 360) + 360) % 360 - 180;
const guaIndex = (i) => Math.floor(((i + 1) % 24) / 3); // 0坎 1艮 2震 3巽 4離 5坤 6兌 7乾
```

### 2.2 坐、向、宅卦

1. 使用者量到的是「面朝外」的方位 = **向**。坐 = `norm(向 + 180)`。
2. 向山 index = 坐山 index + 12(即對山;子↔午、癸↔丁 ...)。
3. 八宅宅卦 = 「坐山」所屬的卦。例:向 180°(午向)→ 坐 0°(子山)→ 坎宅(坐北向南)。
4. 玄空 24 山的山盤、向盤各自取坐山、向山;兼向旗標對坐或向皆可算,因為偏差量相同。例:量到向 175.0° → 坐 355.0° → 子山(dev -5.0°)偏壬側 → 子山午向兼壬丙(陰陽互兼,未超過 5°)。

### 2.3 三元龍與陰陽(兼向分類的基礎)

| 元龍 | 山 |
|---|---|
| 天元龍 | 子 午 卯 酉 乾 坤 艮 巽 |
| 地元龍 | 壬 丙 甲 庚 辰 戌 丑 未 |
| 人元龍 | 癸 丁 乙 辛 寅 申 巳 亥 |

陽:乾 坤 艮 巽 寅 申 巳 亥 壬 甲 丙 庚(12 山);陰:辰 戌 丑 未 子 午 卯 酉 丁 辛 乙 癸(12 山)。每卦內順時針依序為「地元、天元、人元」。已與 sohu、ifeng、36fengshui 三處逐項比對一致。(信心: 高)

### 2.4 兼向與空亡判定(逐步)

輸入:平均後的方位 θ(坐或向皆可)、選項 `threshold`(預設 4.5)、`uncertainty`(預設 3.0)。

1. `i = mountainIndex(θ)`,`dev = deviation(θ, i)`,`adev = |dev|`。
2. `zone = adev <= threshold ? 'zheng'(下卦) : 'jian'(兼向)`。恰好 4.5° 歸下卦(程式約定)。
3. 偏向的鄰山 `j = dev > 0 ? i + 1 : i - 1`(mod 24)。
4. 鄰山分類 `pairType`:
   - `j` 與 `i` 不同卦 → `chugua`(出卦,人元與地元互兼)
   - 同卦且兩者含地元 → `yinyang`(陰陽互兼,地元與天元)
   - 同卦且為天元與人元 → 陰山為 `tongxing_yin`、陽山為 `tongxing_yang`(同性相兼)
5. 限度表(距山中心度數,`[okMax, voidAbove]`):同陰 [6, 6];同陽 [7, 7];陰陽互兼 [5, 6];出卦 [5, 6]。
6. 等級 `level`(僅 `zone = jian` 時細分):`adev <= okMax` → `jian`(可用兼向);`okMax < adev <= voidAbove` → `jian_caution`(注意,來源有 5° 與 6° 兩說);`adev > voidAbove` → `void`(落入差錯/出卦/空向區)。
7. `boundaryDist = 7.5 - adev`(到最近山界的度數)。`boundaryKind = 'gua'`(卦界,大空亡線)或 `'shan'`(山界,小空亡線)。
8. `onLine = boundaryDist < 0.5`(騎線)。`kongwangKind` 僅在 `void` 或 `onLine` 時顯示:卦界 → 大空亡,山界 → 小空亡。
9. `retest = boundaryDist < uncertainty`(量測不確定度會跨過山界,建議重測)。預設 uncertainty = 3.0° 時,`retest` 恰等於「落在兼向區」。
10. 八宅只看 45° 一卦:當 `boundaryKind = 'gua'` 且 `boundaryDist < max(uncertainty, 3)` 時,提示「接近八卦分界,宅卦可能是 X 宅或 Y 宅」。

### 2.5 完整參考實作(已對 fixtures 執行 150/150 通過)

```js
'use strict';
const MOUNTAINS = [...'子癸丑艮寅甲卯乙辰巽巳丙午丁未坤申庚酉辛戌乾亥壬']; // 順時針,index 0 = 子(中心 0°)
const GUA  = ['坎', '艮', '震', '巽', '離', '坤', '兌', '乾'];
const DIR8 = ['北', '東北', '東', '東南', '南', '西南', '西', '西北'];
const TIAN = new Set([...'子午卯酉乾坤艮巽']);
const DI   = new Set([...'壬丙甲庚辰戌丑未']);           // 其餘 8 山為人元龍
const YANG = new Set([...'乾坤艮巽寅申巳亥壬甲丙庚']);   // 其餘 12 山為陰
const LIMITS = { tongxing_yin: [6, 6], tongxing_yang: [7, 7], yinyang: [5, 6], chugua: [5, 6] }; // [okMax, voidAbove]

const norm = (b) => ((b % 360) + 360) % 360;
const mountainIndex = (b, ring = 'earth') => {
  b = norm(b);
  if (ring === 'earth') return Math.floor(((b + 7.5) % 360) / 15) % 24;   // 地盤正針(預設)
  if (ring === 'ren')   return (Math.floor(b / 15) + 1) % 24;             // 人盤中針:子中心 352.5°
  return Math.floor(b / 15) % 24;                                          // 天盤縫針:子中心 7.5°
};
const guaIndex = (i) => Math.floor(((i + 1) % 24) / 3);
const deviation = (b, i) => (((norm(b) - 15 * i + 180) % 360) + 360) % 360 - 180; // [-7.5, 7.5)

function pairType(i, j) {
  if (guaIndex(i) !== guaIndex(j)) return 'chugua';
  const a = MOUNTAINS[i], b = MOUNTAINS[j];
  if (DI.has(a) || DI.has(b)) return 'yinyang';
  return YANG.has(a) ? 'tongxing_yang' : 'tongxing_yin';
}

function analyze(bearing, { threshold = 4.5, uncertainty = 3.0 } = {}) {
  const i = mountainIndex(bearing);
  const dev = deviation(bearing, i);
  const adev = Math.abs(dev);
  const zone = adev <= threshold ? 'zheng' : 'jian';
  const j = (i + (dev > 0 ? 1 : 23)) % 24;
  const type = pairType(i, j);
  const [okMax, voidAbove] = LIMITS[type];
  const level = zone === 'zheng' ? 'zheng'
    : adev <= okMax ? 'jian' : adev <= voidAbove ? 'jian_caution' : 'void';
  const boundaryDist = 7.5 - adev;
  const boundaryKind = guaIndex(i) !== guaIndex(j) ? 'gua' : 'shan';
  const onLine = boundaryDist < 0.5;
  return {
    mountain: MOUNTAINS[i], index: i, dev, zone, level,
    leanTo: zone === 'jian' ? MOUNTAINS[j] : null, pairType: zone === 'jian' ? type : null,
    boundaryDist, boundaryKind,
    kongwangKind: level === 'void' || onLine ? (boundaryKind === 'gua' ? 'da' : 'xiao') : null,
    onLine, retest: boundaryDist < uncertainty,
    gua: GUA[guaIndex(i)], dir8: DIR8[guaIndex(i)], opposite: MOUNTAINS[(i + 12) % 24],
  };
}

const sitFromFacing = (facing) => norm(facing + 180);
const toTrue     = (magnetic, D) => norm(magnetic + D);   // D:東偏為正
const toMagnetic = (trueB, D)    => norm(trueB - D);
function circularMean(readings) {                          // 多次量測必須用向量平均
  let s = 0, c = 0;
  for (const x of readings) { s += Math.sin(x * Math.PI / 180); c += Math.cos(x * Math.PI / 180); }
  const r = Math.hypot(s, c) / readings.length;
  return { mean: norm(Math.atan2(s, c) * 180 / Math.PI), r,
           stdDeg: r > 0 && r < 1 ? Math.sqrt(-2 * Math.log(r)) * 180 / Math.PI : 0 };
}
```

實作注意:
- 7.5 的整數倍在二進位浮點數可精確表示,邊界不會因浮點誤差跑掉;但感測器讀數很少剛好落在邊界,UI 不要顯示「剛好在線上」,用 `onLine`(0.5° 內)即可。
- `dev` 的正負代表偏向順時針或逆時針側,給玄空模組決定「兼哪一山」時必須保留正負號。
- 顯示「子山午向兼壬丙」時:坐山偏向 `leanTo`,向山偏向 `leanTo` 的對山(index + 12)。

### 2.6 磁偏角處理(兩種基準)

設定 `northMode ∈ {'magnetic'(預設), 'true'}` 與 `D`(城市預設值或使用者輸入,東偏為正)。

| 輸入來源 | northMode = magnetic(預設) | northMode = true |
|---|---|---|
| 手機羅盤(iOS `webkitCompassHeading`、Android `deviceorientationabsolute` 等;預期皆為磁方位,待真機確認,見第 7 節第 8 點) | 直接用 | `toTrue(讀數, D)` |
| 地圖、平面圖、日照(真方位) | `toMagnetic(真方位, D)` | 直接用 |

- 一律把「使用哪個基準、D 值、日期」與方位一併存檔,避免日後混用。
- 兩種基準得到的 24 山或八卦不同時,並列顯示:「磁北讀法:癸山;真北校正後:子山」。
- 台灣預設 D:用城市表(第 3.5 節)以縣市查表,年變化約 -0.03~-0.04°/年,每年更新一次即可。(信心: 高)

### 2.7 多次量測

1. 至少 3 次,建議 5 次;同一面的左、中、右各量一次。
2. 用 `circularMean`,不可用算術平均:`[359, 1]` 算術平均是 180,圓周平均是 0。
3. 圓周標準差 `stdDeg > 2°` → 提示環境可能有干擾;讀數極差 > 5° → 要求重量。(產品建議,信心: 低)
4. 遠離中位數 10° 以上的讀數視為離群值,自動剔除後再平均。(產品建議,信心: 低)
5. 多次量測後,把 `uncertainty` 設為 `max(3.0, 2 * stdDeg)`。(產品建議,信心: 低)

### 2.8 三針(選項功能)

- 人盤中針:24 山標籤相對地盤逆時針 7.5°,子中心 352.5°;`index = floor(b/15) + 1`。
- 天盤縫針:標籤相對地盤順時針 7.5°,子中心 7.5°;`index = floor(b/15)`。
- 玄空與八宅只用地盤正針;人盤用於消砂(三合派),天盤用於納水(三合派)。App 預設關閉,不要混進坐向判定。
- 起源有多種說法(磁偏角修正說、天文歲差說、經驗說),各家不一,不影響實作。(信心: 低)

### 2.9 分金格(選項)

一山 5 格、每格 3°:`cell = floor((dev + 7.5) / 3)`,0~4;中三格(1、2、3)= 下卦,外兩格(0、4)= 兼向。注意 `dev = +4.5` 恰為 cell 4 的起點,與 2.4 步驟 2「恰 4.5° 歸下卦」的約定不同;若 UI 要顯示格子,以 `zone` 為準,格子只做視覺參考。

## 4. 流派分歧與建議預設

### 4.1 「向」怎麼取(宅向 vs 門向,以及各建築類型)

**名詞**:
- **坐**:背後,靠山側;**向**:面前,納氣側(氣口)。立向的本質是先決定「坐山」的度數,坐山定了向山自然確定(ifeng 立向文)。
- **宅向**:整個住宅取氣、面對外局(明堂、道路、開闊處、主採光面)的方向,玄空飛星的山向、八宅的宅卦都以它為準。
- **門向**:大門的朝向。八宅另外用「大門落在宅中心的哪個方位」看遊年星(門位),門位是位置,不等於宅向。傳統八宅通俗文章「以大門所向決定坐向」(站在屋內中心點面向大門為向),是把門向當成宅向的簡化做法。
- 現代大樓常見「大門開向走廊,與採光面不同向」,這時宅向與門向分開才有意義。

**各派主張(有出處)**:

| 主張 | 內容 | 來源 |
|---|---|---|
| 以門立向(傳統) | 古代獨院、三合院、四合院大門在正面,門、採光面、外局一致;八宅通俗版以大門定坐向 | ailan、yiqibazi、secretchina、sina 八宅 |
| 陽台/落地窗/最大採光面(現代台灣通行) | 「有陽台者以陽台優先,沒有再用大門」;大樓以客廳最大採光面或落地窗;公寓大門對走廊,採光面小,不論為向 | hhh 幸福空間、ailan、jiaofengshuigo、yiqibazi「以陽為向」 |
| 氣口實際使用 | 城市高樓:總門常鎖、陽台門常開,故總門與陽台門並重,其次常開的窗 | astrogeocity |

**建議預設(產品政策,信心: 低)**:

**App 引導使用者的白話問題(依序,每題一句)**:

1. 「你住的是哪一種?」(電梯大樓/公寓、透天/別墅、店面、辦公室)
2. 「客廳最大的窗戶或陽台,朝哪一邊?」(請站在那一面前,面朝外量測)
3. 「那一面外面是開闊的嗎?」(馬路、公園、中庭、景觀 = 是;貼著隔壁大樓牆壁 = 否;否的話請改選另一面)
4. 「大門開向哪一邊?」(站在門內面朝外量測)
5. 「大門和大窗是不是同一側?」(同側 → 直接用;不同 → 進入三選一:大窗面/大門面/整棟大樓正面)
6. 「你住幾樓?」(大樓)≥ 10 樓提示「高樓層多以自家景觀面為準」;≤ 9 樓提示「部分老師以整棟大樓正面為準」

8. 「一樓有獨立出租嗎?」(透天)有 → 以自住入口為準(17rent)

### 4.2 兼向下卦門檻

| 說法 | 內容 | 流通度 |
|---|---|---|
| ±4.5°(中間 9°) | 沈氏玄空學;五格分金中間三格為下卦 | 玄空圈最通行。xuankongguan(香港陳癸龍)稱「玄空後學自以四度半為圭臬」 |
| ±3.5° | 香港部分學者;陳癸龍本人「三度半臨縫用正、四度半臨縫用兼」,視氣蓄局細而定 | 少數 |
| ±3° | 36fengshui、sina 文 | 少數,且來源品質較低 |

**建議預設 4.5°**,設定內提供 4.5 / 3.5 / 3.0 三檔。

### 4.3 陰陽互兼、出卦限度(5° 或 6°)

- 36fengshui:陰陽互兼與出卦皆「不得超過五度」。
- zggdfs:陰陽互兼「以山中心 6° 為限」,靠外 1.5° 為差錯;出卦同樣不超 6°,最外 1.5° 最凶。
- yixiansheng 4527:地元卦兼向不超 5°,超過 6° 為出卦。

**建議預設**:以 (okMax, voidAbove) = (5, 6) 兩段式:5° 以內可用;5~6° 顯示「注意」;超過 6° 顯示「差錯/出卦」警示。同陰 6°、同陽 7° 為兩個來源一致,直接採用。

### 4.4 大小空亡定義與帶寬

- 位置式定義(sohu、zggdfs、yixiansheng 4527):卦界 = 大空亡,山界 = 小空亡。
- 度數式定義(36fengshui):陰陽差錯 = 小空亡,出卦 = 大空亡。
- 帶寬:±3°(yixiansheng 4527 的度數表)、±2.5°(同頁文字)、±1.5°(zggdfs)。

**建議預設**:在演算法中同時輸出兩者。主要警示以度數式限度(2.4 步驟 6)為準;`kongwangKind`(大/小)只是位置標籤。「騎線」用 0.5°。

### 4.5 三針與磁偏角起源

- 玄空、八宅:只用地盤正針(sohu 274267505、sohu 346292839)。
- 三合派:人盤消砂、天盤納水(fushantang)。
- 起源:磁偏角修正說(yixiansheng 4896 引李約瑟、曹盛健 udn)、天文歲差說、經驗說(fushantang:楊、賴實踐得出 7.5° 誤差)並存。**不影響 App 實作**,預設只用地盤。

### 4.6 是否校正磁偏角

| 主張 | 依據 | 來源 |
|---|---|---|
| 不校正,風水本就用磁北 | 「風水講的是電磁性質的能量,羅盤方向指磁北,不是真北或極北」;智慧型手機 App 若給真北反而不好 | michaeloon.com;fushantang(地盤 = 地磁方位);gerryliao pixnet(古人用磁北,現代若改正北須整套邏輯一併重建);polaris-hs.jp(家相與風水多用磁北,尤其是風水) |
| 應校正,以真北為準 | 磁北會移動;現今磁北與真北差 3~9°(日本)或約 5°(台灣),已超過分金精度 | polaris-hs.jp 作者本人主張真北;vocus 陳昱勳文(但該文符號寫反,見 5.6 與 fixtures) ;fengshuitricks 把「偏角調整」列為選羅盤的重要功能 |

**建議預設:不校正(磁北)**,理由:(1) 與實體羅盤和多數風水師的讀法一致,使用者拿 App 結果去和老師對照才不會對不上;(2) 手機羅盤本身讀磁方位,不需要位置權限;(3) 若要校正,才需要 D 值與日期。同時:設定內放明顯的「真北校正」開關與城市預設 D;兩種讀法落在不同山或不同卦時並列提示。(信心: 中)

### 4.7 量測位置(門內或門外)

- 建議屋外、窗外或陽台外緣量測:fengshuiweb.co.uk(站在建築外;被擋時站在窗前,把羅盤伸出窗外)、jiaofengshuigo(屋外 3~5 公尺,不在屋內量)、michaeloon(不要貼著大門量,門鎖與信箱是金屬)、fengshuitricks(遠離門把與金屬)。
- 屋內面向屋外:hhh 幸福空間(站在屋內面向屋外量測,背面為坐);thefengshuiacademy(把門內朝外列為多個量測點之一)。
- **建議預設**:優先在窗前或陽台外緣面朝外量;不得已在室內時,標記「室內量測,可信度低」,並要求多點多次量測。
- 「上午 9~11 點磁場較穩定」只見於 miao-xian 單一頁面,未找到任何可靠依據,**不列入 UI**。

## 7. 未解決問題

1. **±4.5° 是否為沈氏原文**:多個二手來源一致轉述,未取得沈竹礽《沈氏玄空學》原文;36fengshui/sina 的 ±3° 是否為筆誤或另一支傳承,無法判定。
2. **陰陽互兼與出卦的 5° 與 6° 之爭**:36fengshui 與 zggdfs 不一致,yixiansheng 4527 說法處於兩者之間。目前以兩段式處理,需要玄空專家或原典裁決。
3. **空亡帶寬**:±1.5°、±2.5°、±3° 三種數字並存,連 yixiansheng 同頁也自相矛盾。
4. **大/小空亡的定義**:位置式與度數式並存;三合派另有龜甲空亡等名目,本研究未展開。
5. **人盤/天盤偏移方向與「左/右」的觀看基準**:目前依 fushantang(逆時針/順時針)與 loktin(左/右)一致採用,建議用實體三合羅盤實測覆核。
6. **樓層規則**:9 樓(8、10)以下用大樓正面的規則,只見於 Lillian Too/WOFS 與 FengShuied 的轉述,缺台灣師傅的直接來源。店面與辦公室的立向來源品質偏弱,目前的建議預設信心為低。
7. **台灣官方磁偏角數據**:未找到氣象署或國土測繪中心的現行公告數字(氣象署頁面只有磁場強度,沒有偏角)。台灣網頁上的 -3~-4° 是舊資料。本研究採 WMM2025/IGRF-14 並以獨立網站、香港與日本官方數字交叉核對。
8. **手機平台實際行為**:iOS `webkitCompassHeading` 是否一律為磁方位(預期是)、Android `deviceorientationabsolute` 的 alpha 是否參考磁北,需要在真機上驗證;Capacitor 專案要確認所選插件回傳的是磁方位還是真方位,並避免重複校正。
9. **WMM 模型自身誤差**:本研究未取得官方的偏角誤差數字;跨到 2030 年以後必須換新模型。App 內建城市表建議每年更新,年變化約 -0.03~-0.04°/年(台灣)。
10. **分金格邊界歸屬**:4.5° 邊界(含或不含)與 cell 計算不一致的問題,本研究僅以 `zone` 約定處理。
11. **不規則建築**:L 型、弧形、傾斜建築(thefengshuiacademy 提到傾斜建築取中間度數)的向,尚未設計輸入方式。
